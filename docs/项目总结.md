## 🏗️ 技术架构

### 前端架构
```
├── React 19 (函数组件 + Hooks)
├── TypeScript (类型安全)
├── Vite (构建工具)
├── CSS3 (现代样式)
└── 响应式设计 (移动优先)
```

### 后端架构
```
├── FastAPI (Web框架)
├── SQLite (数据库)
├── Uvicorn (ASGI服务器)
├── Pydantic (数据验证)
└── 异步处理 (性能优化)
```

### 数据模型
```python
# 订阅源表
feeds(id, name, url, category, interval, status, items_count)

# 文章表
articles(id, feed_id, title, url, content, summary, read_status)
```

## 🚀 部署和使用

### 快速启动
```bash
# 1. 构建前端
cd castmind/frontend
npm install
npm run build

# 2. 启动后端
cd castmind/backend
python main.py

# 或使用启动脚本
./start.sh
```

### 访问地址
- **主界面**: http://localhost:8888
- **API文档**: http://localhost:8888/api/docs
- **健康检查**: http://localhost:8888/api/health

### 核心API
```bash
# 创建示例订阅源
POST /api/samples/feeds

# 获取订阅源列表
GET /api/feeds

# 获取文章列表
GET /api/articles

# 获取系统统计
GET /api/stats
```
